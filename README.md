# Сразу посмотреть сайт (без лишнего)

Окей, делаем максимально просто.

## Где лежит проект в этой среде
Абсолютный путь:

- `/workspace/Chat`

Проверить можно командой:

```bash
pwd
```

Показать файлы проекта:

```bash
ls -la /workspace/Chat
```

---

## 1 команда
В папке проекта запусти:

```bash
./start.sh
```

После этого просто открой ссылку:

- `http://localhost:4173`

Готово — увидишь сайт сразу в браузере.

---

## Если `./start.sh` не запускается
Дай права и запусти:

```bash
chmod +x start.sh
./start.sh
```

---

## Что уже лежит в проекте
- `index.html` — сама страница.
- `styles.css` — стили страницы.
- `start.sh` — запуск локального просмотра одной командой.

---

## Альтернатива без скрипта
```bash
python3 -m http.server 4173
```
Потом открыть `http://localhost:4173`.
